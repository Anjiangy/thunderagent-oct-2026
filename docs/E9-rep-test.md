## 结论：单次 79.79% 是异常值

| 臂 | 观测 | 均值 |
|---|---|---|
| 裸 TA | 75.22（n=1，另一轮失败） | — |
| affinity | 76.61 / 72.91 | 74.8 |
| sticky | 73.19 / 69.90（**另有早期 79.79 一次**） | 71.5（含早期为 74.3） |

- **组内波动 > 组间差异**：sticky 两次相差 3.3 pt，aff 相差 3.7 pt，而三臂的均值差只有 1~3 pt。早期那次 79.79% 落在分布之外，不能当结论。
- **dq 也没对齐**（0.73× ~ 0.95×）：命中率对负载规模敏感，dq 相差 30% 时比较命中率本身就不严谨。
- **sticky 这次更差**：它把 19% 压到 A（A 命中只有 59.4% 的那轮），说明"减掉自己再比"的规则在负载动态变化时会把 program 反复挪到更空的卡，反而打散了驻留。

## 因此

E9 这一格的正确结论是：**Mod 的三种放置在两卡同构、负载 0.8~0.95× 的场景下与裸 TA 无显著差异**；此前报告的 +2.9 pt 不成立。

要做出可信结论，需要：①每臂 ≥5 次；②把 dq 对齐到同一区间（按 dq 分层比较）；③固定 gap 序列（同一 salt + 同一随机源）。这三点我还没做。
