## 为什么没差异：装置构造失败，不是机制结论

- 预热时我按 `i % 2` 交替把 KV 放到 A/B（8/8）。
- TA 起手是空表、按"剩余容量最大"分配，于是它也是 p0→A、p1→B、p2→A… **交替**。
- 两者恰好重合 ⇒ **错配率 ≈ 0**，两臂自然一样。这一格测到的是"零错配"，不是"错配的代价"。

## 正确的构造（下次照这个改）

把**全部** program 的 KV 预热到**同一张卡**，让 TA 自己去均分：

1. `N=12`、每 program ≈9k token → 全放 B 时 B 用 108k < 114k **不越线**；
2. TA 自由分配会让约 6 个落到 A → **错配率 ≈50%**；
3. `pin` 臂把 12 个全钉在 B（108k 仍在容量内）→ 零错配；
4. 判据不变：`pin.sum_p50` 比 `free` 低 ≥10% 才算"错配代价真实"。

代码只需改一处：`home = {p: B for p in pids}`，并把 N 从 16 降到 12。
