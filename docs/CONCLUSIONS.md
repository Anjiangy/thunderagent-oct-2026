# 结论总表（E/M 系列合并）

汇总 2026-10-23 ~ 10-30 全部实验的**结论**，每条带判据、数字、出处。口径先写清：单卡 plain 引擎 `--max-model-len 12288 --gpu-memory-utilization 0.80 --enable-prefix-caching` 时 **892 块 × 128 = 114,176 token/卡**；三卡集群 342,528。

## 五、五条可以写进设计的规则

1. **只搬一次，永不两跳**（E3d 判据恒不成立）。
2. **前缀 ≳4k token 才值得搬**，否则直接重算更快（E3d 平衡点）。
3. **目的地只要余量够就行**，不必按剩余空间排序（E3 三组实验全平）。
4. **定额按需求算**：`ceil((D−K)/p̄)`，不是“能搬就搬”（E4e 2.6× vs 0）。
5. **时机门不要用历史间隔**，它在等间隔负载上必然退化；短会话（≤5 轮）里根本来不及触发（E4b–E4i）。
